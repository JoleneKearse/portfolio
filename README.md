# Meet Jolene

## Project Preview

[Visit the live site](jolenekearse.dev)

Jolene Kearse's portfolio offers a quick, stylish way for potential employers & collaborators to check out her work.

The **skills** page features drop-downs to allow views to get an overview or read more details.

The **contact** section is likewise short and sweet.

The **projects** page displays the showcased projects in clickable cards to find out more details.

It also has a protected route where the owner can update projects.
